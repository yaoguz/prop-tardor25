JOC DE PROVA - DRIVER RESPUESTA
================================

SCRIPT DE PRUEBA MANUAL
------------------------

1. INICIAR DRIVER:
   ./gradlew runDriverRespuesta

2. SECUENCIA DE PRUEBAS:

DATOS INICIALES:
- Usuarios: ana, pol, joan
- Encuestas: ID=1
- Preguntas: 4 preguntas, una de cada tipo

PRUEBA 1: Crear respuesta numerica
--------------------------------
Opcion: 1
Usuario: ana
Respuesta: 10
Resultado esperado: "Respuesta creada con ID: 1"

PRUEBA 2: Crear respuesta opcion unica
--------------------------------
Opcion: 2
Usuario: pol
Respuesta: 1
Resultado esperado: "Respuesta creada con ID: 2"

PRUEBA 3: Crear respuesta opcion multiple
--------------------------------
Opcion: 3
Usuario: joan
Respuesta: 0,2,3
Resultado esperado: "Respuesta creada con ID: 3"

PRUEBA 4: Crear respuesta libre
--------------------------------
Opcion: 4
Usuario: ana
Respuesta: Salgo a correr todos los dias
Resultado esperado: "Respuesta creada con ID: 4"

PRUEBA 5: Modificar respuesta
-------------------------------------
Opcion: 5
ID de la respuesta a modificar: 2
Nueva respuesta: 0
Resultado esperado: "Respuesta modificada"

PRUEBA 6: Eliminar respuesta
-------------------------------------
Opcion: 6
ID de la respuesta a eliminar: 4
Nueva respuesta: 0
Confirmar: s 
Resultado esperado: "Respuesta eliminada"

PRUEBA 7: Consultar respuesta por ID
-------------------------------------
Opcion: 7
ID de la respuesta a consultar: 3
Resultado esperado:
    ID: 3
    Usuario: joan
    ID pregunta: 3
    Enunciado: Qué deportes practicas? (seleccion multiple)
    Tipo: opción múltiple
    Opciones: Futbol, Natación, Running

PRUEBA 8: Listar todas las respuestas
-------------------------------------
Opcion: 8
Resultado esperado: 
    --- Todas las respuestas ---
    Total: 3
    [  1] NUM  | Usuario: ana        | Pregunta:   1 | 10.0
    [  2] OPU  | Usuario: pol        | Pregunta:   2 | opcion 0
    [  3] OPM  | Usuario: joan       | Pregunta:   3 | 3 opciones

PRUEBA 9: Listar respuestas de un usuario
-------------------------------------
Opcion: 9
Usuario: ana
Resultado esperado: 
    Respuestas de ana: 1
    [  1] NUM  | Usuario: ana        | Pregunta:   1 | 10.0

PRUEBA 10: Listar respuestas de una pregunta
-------------------------------------
Opcion: 10

    Pregunta: Cuál es tu nivel de actividad física?
    Respuestas: 1
    [  2] OPU  | Usuario: pol        | Pregunta:   2 | opcion 0
