JOC DE PROVA - DRIVER RESPUESTA
================================

SCRIPT DE PRUEBA MANUAL
------------------------

1. INICIAR DRIVER:
   ./gradlew runDriverRespuesta

2. SECUENCIA DE PRUEBAS:

DATOS INICIALES:
- Usuarios: user1, user2, user3
- Encuestas: ID=1, ID=2
- Preguntas: Varios tipos asociados a encuestas

--------------------------------

ID pregunta: 1

Resultado esperado: "Respuesta libre creada"

----------------------------------

VALORES PROBADOS:
- Caja negra: Creacion de 4 tipos de respuestas
- Validaciones especificas por tipo:
  - Numerica: NaN, Infinito
  - Opcion Unica: Indice negativo
  - Opcion Multiple: Duplicados, array vacio
- Consultas: Por usuario, encuesta, pregunta
- Modificaciones: Valor, texto, indices

RESULTADO ESPERADO:
- Cada tipo de respuesta se crea y valida correctamente
- Validaciones detectan valores invalidos
- Consultas devuelven datos correctos
- Asociacion respuesta-usuario-pregunta se mantiene
- Polimorfismo: Comportamiento especifico por tipo
