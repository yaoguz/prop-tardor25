/src/test/java/domaincontrollers

Este directorio contiene todos los ficheros con los tests de los controladores de dominios.

Descripcion de los ficheros:

- index.txt:
    Este archivo. Contiene la informacion del directorio y su contenido.

-TestCtrlDominioEncuesta.java:
    La clase testeadora del controlador dominio encuesta.

-TestCtrlDominioPerfil.java:
    La clase testeadora del controlador dominio perfil.

-TestCtrlDominioPregunta.java:
    La clase testeadora del controlador dominio pregunta.

-TestCtrlDominioRespuesta.java:
    La clase testeadora del controlador dominio respuesta.

-TestCtrlDominioUsuario.java:
    La clase testeadora del controlador dominio usuario.
