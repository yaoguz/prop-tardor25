/src/main/java/persistence

Este directorio contiene las clases de la capa de persistencia.

Descripcion de los ficheros:

- index.txt:
    Este archivo. Contiene la informacion del directorio y su contenido.

- GestorPersistencia.java:
    Fachada principal del sistema de persistencia. Coordina todos los gestores especializados.

- GestorPersistenciaUsuario.java:
    Gestor de persistencia para usuarios. Mantiene cache en memoria y gestiona operaciones lectura/escritura.

- GestorPersistenciaEncuesta.java:
    Gestor de persistencia para encuestas. Mantiene cache en memoria y gestiona operaciones lectura/escritura.

- GestorPersistenciaPregunta.java:
    Gestor de persistencia para preguntas. Mantiene cache en memoria y gestiona operaciones lectura/escritura.

- GestorPersistenciaRespuesta.java:
    Gestor de persistencia para respuestas. Mantiene cache en memoria y gestiona operaciones lectura/escritura.

- CtrlPersistenciaUsuario.java:
    Controlador de persistencia en disco para usuarios. Lee y escribe archivos JSON.

- CtrlPersistenciaEncuesta.java:
    Controlador de persistencia en disco para encuestas. Lee y escribe archivos JSON.

- CtrlPersistenciaPregunta.java:
    Controlador de persistencia en disco para preguntas. Lee y escribe archivos JSON.

- CtrlPersistenciaRespuesta.java:
    Controlador de persistencia en disco para respuestas. Lee y escribe archivos JSON.
