✅ VENTAJAS DE SEPARAR:

1. SINGLE RESPONSIBILITY PRINCIPLE
   • CtrlUsuario: Gestiona lógica de usuarios (validaciones, búsquedas, CRUD)
   • CtrlPersistence: Solo se ocupa de I/O (lectura/escritura)

2. CAMBIAR FORMATO DE PERSISTENCIA ES FÁCIL
   • Hoy: JSON
   • Mañana: Base de datos SQL → Solo cambiar CtrlPersistence
   • Controladores de clase NO cambian

3. TESTABILIDAD
   • Tests unitarios: Usan CtrlUsuario sin tocar disco (mock CtrlPersistence)
   • Tests de integración: Verifican CtrlPersistence con archivos reales

4. PERFORMANCE
   • Operaciones en memoria (CtrlUsuario) son RÁPIDAS
   • Solo escribir a disco cuando sea necesario (CtrlPersistence)

5. SEPARACIÓN DE CONCERNS
   • CtrlUsuario: Lógica de negocio
   • CtrlPersistence: Infraestructura (I/O)
