Aquí tienes **las excepciones más comunes y más usadas en Java**, explicadas de forma clara, con ejemplos y con la intuición detrás. Esto es exactamente lo que suele preguntar alguien que está programando o estudiando Java.

---

# ✅ **1. NullPointerException (NPE)**

La más famosa.

> Llamas a un método o accedes a un campo sobre una referencia `null`.

Ejemplo:

```java
String s = null;
s.length();   // ❌ NullPointerException
```

---

# ✅ **2. ArrayIndexOutOfBoundsException**

> Accedes a un índice fuera del rango.

Ejemplo:

```java
int[] arr = {1,2,3};
arr[5];   // ❌
```

---

# ✅ **3. IndexOutOfBoundsException**

Versión general para listas, strings, etc.

```java
List<Integer> l = List.of(1,2,3);
l.get(5);  // ❌
```

---

# ✅ **4. ClassCastException**

> Intentas hacer un cast a un tipo incompatible.

Ejemplo:

```java
Object x = "hola";
Integer y = (Integer) x;   // ❌ ClassCastException
```

---

# ✅ **5. NumberFormatException**

> Intentas convertir texto a número y no se puede.

```java
Integer.parseInt("abc");   // ❌
```

---

# ✅ **6. IllegalArgumentException**

> El argumento pasado a un método no tiene sentido.

Ejemplo:

```java
Thread.sleep(-5);  // ❌ parámetro inválido
```

---

# ✅ **7. IllegalStateException**

> El **estado del objeto** no permite esa operación.

Ya te lo expliqué:

* El método es válido
* Pero el objeto NO está listo para ejecutarlo

```java
Scanner sc = new Scanner(System.in);
sc.close();
sc.nextLine();   // ❌ objeto cerrado
```

---

# ✅ **8. UnsupportedOperationException**

> Llamas a un método no soportado en esa implementación.

Ejemplo típico:

```java
List<Integer> l = List.of(1,2,3);  // lista inmutable
l.add(4);   // ❌ no soportado
```

---

# ✅ **9. ArithmeticException**

> Error aritmético, típico: dividir entre cero.

```java
int x = 5 / 0;  // ❌ ArithmeticException
```

---

# ✅ **10. IOException**

> Errores de entrada/salida: ficheros, sockets, etc.

Ejemplo:

```java
new FileInputStream("noExiste.txt");   // ❌ IOException
```

---

# ✅ **11. FileNotFoundException**

Tipo de IOException.

---

# ✅ **12. InterruptedException**

> Ocurre cuando un thread es interrumpido mientras está esperando, durmiendo…

```java
Thread.sleep(1000);  // puede lanzar InterruptedException
```

---

# ✅ **13. SQLException**

> Para errores de bases de datos (JDBC).

---

# ✅ **14. RuntimeException**

Superclase de muchas excepciones comunes (NPE, IOB, CCE…).

---

# ✅ Clasificación rápida para que te quede claro

### ✅ **Runtime Exceptions** (NO requieren try-catch obligatorio)

* NullPointerException
* ClassCastException
* ArithmeticException
* IllegalArgumentException
* IndexOutOfBoundsException
* IllegalStateException

Estas indican errores de programación.

---

### ✅ **Checked Exceptions** (requieren try-catch o throws)

* IOException
* SQLException
* FileNotFoundException
* InterruptedException

Estas indican errores *esperados* en el entorno.
