/src/main/java

Este directorio contiene todos los ficheros con el codigo de las clases java.

Descripcion de los directorios:

- /domain:
    Contiene los ficheros de codigo java de la capa del dominio (incluyendo el algoritmo).

- /domaincontrollers:
    Contiene los ficheros de codigo java de los controladores del dominio.

- /drivers:
    Contiene los ficheros de codigo java de los drivers.

- /persistence:
    Contiene el fichero de codigo java de la capa de persistencia.

- /presentation:
    Contiene los ficheros de codigo de la capa de presentacion.

Descripcion de los ficheros:

- index.txt:
    Este archivo. Contiene la informacion del directorio y su contenido.

- main.java:
    El codigo java del programa principal. Actualmente no hace nada, se modificará para las siguientes entregas.
