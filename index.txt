PROYECTO PROP - SUBGRUP 11.5
=============================

DESCRIPCION:
Sistema de gestion de encuestas con clustering de usuarios (K-means, K-means++, K-medoids).

CONTENIDO:
- miembros.txt: Equipo y emails
- index.txt: Este fichero
- README.md: Instrucciones compilacion y ejecucion
- compilar.sh: Script de compilacion
- build.gradle: Configuracion Gradle
- settings.gradle: Nombre proyecto
- gradlew, gradlew.bat: Gradle wrapper

DIRECTORIOS:
- DOCS/: Documentacion (javadoc, UML, estructuras de datos)
- EXE/: Ejecutables (drivers) y jocs de prova
- src/: Codigo fuente (main/java, test/java)
- gradle/: Wrapper de Gradle
- build/: Generado por Gradle (NO ENTREGAR)

COMPILAR:
./compilar.sh

EJECUTAR DRIVERS:
./gradlew runDriverUsuario
./gradlew runDriverEncuesta
./gradlew runDriverPregunta
./gradlew runDriverRespuesta
./gradlew runDriverClustering

EJECUTAR TESTS:
./gradlew test

JOCS DE PROVA:
Cada driver en EXE/ tiene:
- DESCRIPCION.txt: Casos de uso, datos, operativa
- Archivos de datos (si aplica)

ESTRUCTURA EXE/:
EXE/
  DriverUsuario/
    DESCRIPCION.txt
  DriverEncuesta/
    DESCRIPCION.txt
  DriverPregunta/
    DESCRIPCION.txt
  DriverRespuesta/
    DESCRIPCION.txt
  DriverClustering/
    DESCRIPCION.txt
    datos-encuestas.json
    respuestas-deportes.csv
    encuesta-deportes.json

TECNOLOGIAS:
- Java 21
- Gradle 7.x
- JUnit 4
- Mockito
- Gson

NOTAS:
- NO usar javac directamente, siempre Gradle
- NO incluir build/ en entrega
- Paths siempre relativos al proyecto
- Consultar README.md para mas detalles
