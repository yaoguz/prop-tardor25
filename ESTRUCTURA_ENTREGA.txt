FICHEROS IMPORTANTES:

miembros.txt:
- Lista nombres y emails del equipo

index.txt:
- Descripcion proyecto
- Estructura directorios
- Instrucciones basicas

README.md:
- Instrucciones compilacion
- Comandos ejecucion drivers
- Comandos tests

compilar.sh:
- Script compilacion con Gradle
- Ejecutar: ./compilar.sh

JOCS DE PROVA (EXE/):
Cada driver tiene subdirectorio con:
- DESCRIPCION.txt: Objecte, valors estudiats, operativa
- Datos de prueba (si aplica)

DriverClustering incluye:
- datos-encuestas.json: Encuesta ejemplo
- respuestas-deportes.csv: Respuestas usuarios
- encuesta-deportes.json: Encuesta deportes

INSTRUCCIONES USO:

1. Compilar:
   ./compilar.sh

2. Ejecutar driver:
   ./gradlew runDriverUsuario
   ./gradlew runDriverEncuesta
   ./gradlew runDriverPregunta
   ./gradlew runDriverRespuesta
   ./gradlew runDriverClustering

3. Ejecutar tests:
   ./gradlew test

4. Ver javadoc:
   DOCS/javadoc/index.html

5. Limpiar:
   ./gradlew clean

NOTAS:
- Usar Gradle, NO javac
- Paths relativos siempre
- build/ no entregar
- Consultar DESCRIPCION.txt en cada driver
