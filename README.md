# PROYECTO PROP - SUBGRUP 11.5 - ENTREGA 3

Sistema de gestión de encuestas con clustering de usuarios.

## Generar el ejecutable

```bash
./gradlew jar
```

## Ejecutar el ejecutable

```bash
java -jar EXE/subgrup-prop11.5-3.0-SNAPSHOT.jar
```

## Compilar manualmente

```bash
./compilar.sh
```

O manualmente:
```bash
./gradlew build
```

## Ejecutar el programa manualmente

```bash
./gradlew runAll
```

## Ejecutar Tests

```bash
./gradlew test
```

## Limpiar

```bash
./gradlew clean
```

## Estructura Entrega

```
DOCS/       - Documentación
EXE/        - Ejecutable y datos de prueba
src/        - Código fuente
build.gradle - Configuración Gradle
compilar.sh - Script de compilación
```
